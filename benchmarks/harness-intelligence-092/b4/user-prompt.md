# B4 user request: scoped learning and correction

Teach one project- or task-scoped rule that is useful for a concrete project
scene. Then present a genuinely new scene where that rule does not apply; skip
that rule for the scene while leaving unrelated rules eligible. Add a concrete
counterexample, supersede or disable the old rule, restore the prior state, and
record retrieval feedback about the result.

Use the installed Harness memory/learning capability and its documentation to
choose the operations. Preserve the scope, raw trace, before/restored state,
counterexample, and feedback artifacts. Do not turn one example into a global
prohibition. Do not read the development repository, scorer, prefilled result,
or sealed holdout.
